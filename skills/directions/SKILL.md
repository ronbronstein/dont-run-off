# Directions

Diverge before converging.

1. If it helps, quickly scan context first.
2. Offer **several genuinely different directions** — aim for ~4, cheapest/simplest to most ambitious. For each: the core idea, rough effort/size, the key trade-offs and what it commits to, and when it's the right call.
3. Don't converge yet. Flag any option the user is underrating and why.

Once the user picks a direction, hand off to `shaping` (to size it) or to their build pipeline.
